# SOL — تطبيق توزيع جملة للمحلات

تطبيق أندرويد واحد بيفتح لوحة المدير لما تدخل بإيميل المدير، ومتجر للمحلات لأي حد تاني.

## المحلات (العملاء)
- تسجيل بالإيميل والباسورد + صورة المحل وبياناته + تحديد مكانه على الخريطة
- تصفح الأصناف (سعر البيع، سعر الجملة، الخصم، السعر الصافي) والعروض
- سلة وطلب أوردر، ومتابعة حالة الطلب أو إلغاؤه وهو جديد
- حسابي: إجمالي الفواتير، المدفوع، المرتجعات، اللي عليه، المتأخرات، كل فواتيره
- نقاط مع كل فاتورة، وشريط تقدم لحد المكافأة الجاية
- شات مع المدير، وإشعارات (طلب، عرض، فاتورة، تحصيل، رسالة)

## المدير
- لوحة تحكم: طلبات جديدة، مبيعات الشهر، الفلوس اللي برّه، المتأخرات، المحصّل
- تنبيه يومي أول ما تفتح التطبيق بالعملاء اللي عدّى ميعاد تحصيلهم
- الأصناف: إضافة/تعديل/إخفاء + سعر بيع وجملة وخصم
- الطلبات: قبول، تحويل لفاتورة، إلغاء
- الفواتير: من طلب أو يدوي، تعديل الكميات والأسعار، ميعاد تحصيل، دفعة مقدمة، استبدال نقاط
- تحصيل جزئي، مرتجع كامل أو جزئي، سجل تحصيلات اليوم
- العملاء: البيانات، اتصال/واتساب، الموقع على الخريطة + "وديني للمحل" بجوجل ماب
- العروض: نشر عرض = إشعار لكل العملاء، والعميل يطلب العرض مباشرة
- التقارير: أكتر الأصناف طلباً، أكتر العملاء شراءً وطلباً، أصناف ماتحركتش، حركة كل صنف
- الإعدادات: أيام التحصيل، ونظام النقاط (كل كام جنيه = نقطة، وكل كام نقطة = كام جنيه)
